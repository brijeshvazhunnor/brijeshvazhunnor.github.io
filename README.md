# Brijesh V.V. — Portfolio

A responsive, single-page AI/ML portfolio built with plain HTML, CSS and JavaScript.

## Run locally

Open `index.html` in a browser.

Or from a terminal:

```bash
cd brijesh-portfolio
python3 -m http.server 8000
```

Then open http://localhost:8000

## Before publishing

1. Add your real `resume.pdf` to this folder.
2. Replace `your.email@example.com` with your email.
3. Replace the GitHub and LinkedIn URLs with your profiles.
4. Optionally add project repository/demo links.
5. Deploy the folder to GitHub Pages, Netlify, Vercel, Cloudflare Pages, or any static hosting provider.

## Notes

No build tools or framework are required.
